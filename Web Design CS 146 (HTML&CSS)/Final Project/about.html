About the Game

How to Play

Choose Game to start. Turn over two cards at a time and look for matching animals. Matched pairs stay face-up; turn over all the pairs to finish. Refresh the game page to play again.


About This Project

This group course project was built with HTML, CSS, and JavaScript. It is a casual matching game for entertainment and is not intended for medical diagnosis or treatment.
